# Evidence index

Where each claimable result lives. This is an index of evidence: it states what was measured, where, and under which split. It contains no interpretation for the informe, which the students write.

Written 2026-10-03 (branch `docs/evidence-pack`, PR #91); updated 2026-10-05 (branch `docs/state-2026-10-05`: onset-informative terms, `onset-prompt-terms-v1`, EXP-B-006 status); earlier update 2026-10-04 (branch `docs/evidence-pack-v2`) with ADR-0014 (EXP-B-004, EXP-Q-001), ADR-0015 (EXP-B-005), the S3 v2, v3 and v3b builds and the deployment facts (sections 7 to 10).

- Every number in the tables below was read from the source file named in the row. `scripts/evidence/verify_numbers.py` re-checks 639 numbers printed in docs against the result files: 635 match at the printed precision and 4 differ (listed under Discrepancies; the same 4 as in v1, none among the 359 numbers added in v2). Output: `data/number_checks.tsv`.
- Numbers in full precision, as markdown tables: [TABLES.md](TABLES.md) (generated by `scripts/evidence/make_tables.py`).
- Figures: [Figures](#figures). Each has a script in `scripts/evidence/`; `python scripts/evidence/make_all.py` regenerates every figure and table from committed result files (needs matplotlib and numpy, which are not in the pinned project environment).
- CIs are 95%. "pub" = paired bootstrap resampling publications (R1); "genes" = resampling genes (S3); "case" = resampling cases.
- Splits: **R1-dev** (free reads), **R1-test (sealed)**, **S3-dev**, **S3-test (sealed)**, **S3-v2-dev**, **S3-v2-test (sealed)**, **S3-v3b-dev**, **S3-v3b-test (sealed)**, **train-side** (R1-train or simulator train data), **eval-only** (MCRD, DDD). The R1 vault was never opened.
- "PR" numbers are in MateAlv/diagnostic.ar-training unless said otherwise.
- Status column of sections 7 and 8: **gated, pre-registered** = a pass/fail rule written before the sealed read; **descriptive** = sealed numbers with no gate, nothing selected from them; **dev** = search on a dev split, free reads.
- On S3 v2 and S3 v3b, "Delta vs E0+answers" is the re-ranker's effect given the interview answers; "primary Delta vs E0-initial" (EXP-Q-001) is interview plus re-ranker against no questions. CIs resample genes (2,000 resamples, seed 0).
