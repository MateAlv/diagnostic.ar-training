# Evidence index

Where each claimable result lives. This is an index of evidence: it states what was measured, where, and under which split. It contains no interpretation for the informe, which the students write.

Written 2026-10-03, branch `docs/evidence-pack`.

- Every number in the tables below was read from the source file named in the row. `scripts/evidence/verify_numbers.py` re-checks 280 numbers printed in docs against the result files: 276 match at the printed precision and 4 differ (listed under Discrepancies). Output: `data/number_checks.tsv`.
- Numbers in full precision, as markdown tables: [TABLES.md](TABLES.md) (generated by `scripts/evidence/make_tables.py`).
- Figures: [Figures](#figures). Each has a script in `scripts/evidence/`; `python scripts/evidence/make_all.py` regenerates every figure and table from committed result files (needs matplotlib and numpy, which are not in the pinned project environment).
- CIs are 95%. "pub" = paired bootstrap resampling publications (R1); "genes" = resampling genes (S3); "case" = resampling cases.
- Splits: **R1-dev** (free reads), **R1-test (sealed)**, **S3-dev**, **S3-test (sealed)**, **train-side** (R1-train or simulator train data), **eval-only** (MCRD, DDD). The R1 vault was never opened.
- "PR" numbers are in MateAlv/diagnostic.ar-training unless said otherwise.
