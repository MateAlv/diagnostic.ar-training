# EXP-A-004f: negation + covariates in a frozen v3.0 (not run)

- **Front:** A
- **Registered:** 2026-09-30, by Mateo Alvarez
- **Status:** **not run, by the rule ADR-0010 set for it**

ADR-0010 defined A-004f as the combination of the configurations *selected*
by EXP-A-002f and EXP-A-003f. Neither selected one:
- EXP-A-002f: no run met S3 harmed ≤ 5%, and R1 "+excluded" −0.14 to −0.28;
- EXP-A-003f: R1 "all" −0.21 to −0.23, harmed 55–60%.

There is nothing to combine. Combining two harmful components would not
test a pre-specified hypothesis, so no configuration was trained and no data
was read for this experiment.
